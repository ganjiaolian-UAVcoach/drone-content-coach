# Data Review

## Required data when available

- publish time;
- views/reach;
- average watch duration or retention;
- completion rate;
- likes;
- comments;
- shares;
- saves/favorites;
- profile visits;
- follows;
- DMs;
- leads;
- business outcomes.

## Diagnose the funnel

### Reach problem

Symptoms: weak exposure or weak audience match.

Possible tests:

- sharper audience framing;
- clearer topic;
- stronger first seconds;
- better visual proof.

### Retention problem

Symptoms: people leave early.

Possible tests:

- remove setup;
- reveal the result earlier;
- use concrete visual proof;
- shorten repeated explanation.

### Trust problem

Symptoms: viewers interact but do not inquire.

Possible tests:

- more real examples;
- demonstrations;
- clear credentials that can be verified;
- transparent process/expectations.

### Conversion problem

Symptoms: good audience fit and trust signals but low action.

Possible tests:

- clearer service boundary;
- clearer next step;
- better matching between topic and offer;
- less vague CTA.

## Review rule

Never infer a hidden platform algorithm from one video. Treat each post as a test and look for patterns across multiple posts.

## Output

Use:

> 数据现象 → 可能原因 → 证据强度 → 下一轮测试 → 观察指标

Label weak hypotheses as hypotheses.
