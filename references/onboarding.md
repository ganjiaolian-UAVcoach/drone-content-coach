# Onboarding: Low-Altitude Content Profile

## Goal

Build a durable user profile before the first serious content recommendation.

## Question order

Ask one question at a time. Stop when enough information is collected; do not force every question if the answer is already known.

### A. Identity

1. 你在低空行业里具体做什么？
2. 你主要服务/销售什么？
3. 你的主要工作地点是哪里？只收集到城市/区域粒度即可，除非用户主动需要具体地址。

### B. Account

4. 使用什么平台？
5. 是企业号、个人号、团队号还是混合运营？
6. 目前账号主要承担什么任务？
7. 是否有现成账号链接、主页截图或后台数据？

### C. Business goal

8. 你最重要的结果是什么？从：曝光、IP、咨询、报名、找活、招徒、产品线索、合作、其他 中选择。
9. 第二重要结果是什么？
10. 什么流量你不想要？例如大量同行、无购买意愿的泛娱乐流量等。

### D. Audience

11. 你最希望谁看到你的内容？
12. 这些人通常为什么会来搜索/刷到你？
13. 他们最犹豫的地方是什么？

### E. On-camera mode

14. 固定真人、多人轮换、偶尔真人、无真人、AI配音、AI数字人？
15. 如果真人出镜，有几个人？谁承担什么专业角色？
16. 谁最自然地面对镜头？谁更适合讲专业？谁更适合讲故事或案例？

### F. Resources

17. 你手上有哪些真实素材：训练场、飞行现场、农田、吊运项目、工厂、设备、学员、客户问题、产品测试等？
18. 一条视频通常能投入多少时间？
19. 能否固定手机机位、补光、收音、剪辑？

### G. Style and boundaries

20. 你不喜欢什么内容风格？
21. 有哪些表达不能接受？
22. 哪些经历、案例或客户信息不能公开？

## Profile completion rule

Create the profile only after summarizing the known facts. Mark uncertain items as `待确认` instead of guessing.
