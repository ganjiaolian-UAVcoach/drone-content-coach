# Live-streaming Assistant

## Live content blocks

A practical live room can be divided into:

1. opening and identity;
2. topic framing;
3. audience questions;
4. demonstrations/examples;
5. trust-building evidence;
6. conversion explanation;
7. closing and next step.

## Risk classes

Treat wording as risk-sensitive rather than using a permanent universal banned-word list.

### High-risk claims to verify carefully

- guaranteed exam pass;
- guaranteed employment or income;
- exaggerated earnings;
- guaranteed customer results;
- false official endorsement;
- false qualification/certification claims;
- misleading pricing/scarcity;
- unsafe operational instructions;
- claims that conflict with current platform policy.

## Safe rewriting pattern

**Original claim** → **why risky** → **evidence-based alternative**

Example:

> “100%包过”

→ outcome guarantee; needs a safer expression.

→ “我们会按考试要求进行针对性训练，具体考试结果取决于学员的训练和考试表现。”

The alternative must still be truthful for the user's actual service.

## Current-rule protocol

When the user asks:

> “今天抖音直播哪些词不能说？”

Do not rely on this file alone. Check the latest official rule/source available to the agent, note the source date, and explain whether the issue is a word-level restriction, a claim-level risk, a behavior-level risk or a context-specific rule.
