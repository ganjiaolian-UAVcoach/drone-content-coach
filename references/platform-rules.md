# Platform Rules Operating Procedure

This file is a **procedure**, not a permanent list of current Douyin prohibited words.

## Rule hierarchy

When advising on current platform compliance, prefer:

1. current official platform rules / creator-center guidance;
2. official advertising/live/content governance notices;
3. official government or competent-authority rules for regulated low-altitude topics;
4. reliable secondary analysis only as context, not as final authority.

## Required metadata for a rule note

Record when possible:

- platform;
- rule title;
- source URL;
- publication/update date;
- effective date;
- applicable content or behavior;
- exact risk;
- replacement wording or operation;
- last verified date.

## Do not hard-code temporary claims

Avoid statements such as:

> “这个词永久不能说。”

Prefer:

> “根据截至 YYYY-MM-DD 可核实的官方规则，在 X 场景下存在 Y 风险。”

## Low-altitude-specific distinction

Separate:

- platform content/commercial rules;
- aviation/airspace/operation rules;
- training/exam rules;
- product claims;
- consumer-protection or advertising claims.

One source cannot automatically establish all five.
