# Script Frameworks

## Universal script skeleton

1. Viewer identity / situation
2. Hook
3. Proof or concrete scene
4. Core value
5. Practical takeaway
6. Soft CTA matching business goal

## Framework 1: mistake correction

> 你如果正在____，先别急着____。  
> 很多人会把____和____混在一起。  
> 真正需要先看的是____。  
> 我给你看现场。  
> [demonstration]  
> 所以如果你属于____，先做____，再考虑____。

## Framework 2: on-the-job story

> 今天现场遇到一个____。  
> 表面看是____，其实问题在____。  
> 我当时先____，再____。  
> 这件事让我一直比较在意____。

## Framework 3: decision guide

> 如果你准备____，别只看____。  
> 真正值得比较的是三件事：____、____、____。  
> 我为什么这么判断？因为____。

## Framework 4: demonstration

> 这一步看起来简单，但现场最容易错在____。  
> [动作]  
> 注意看____。  
> 这就是为什么____。

## Framework 5: team account

For rotating speakers:

- same content promise;
- different speaker expertise;
- unified visual basics;
- speaker-specific language;
- no forced identical personality.

## CTA rules

CTA should answer one action:

- 评论一个问题；
- 私信获取公开资料；
- 预约了解服务；
- 看主页某个固定内容；
- 联系进行项目咨询。

Avoid manipulative urgency, false scarcity, guaranteed outcomes and misleading promises.

## Output requirements

When the user asks for a full script, output:

- 选题
- 目标观众
- 谁出镜
- 核心价值
- 开头 3–5 秒
- 完整口播
- 分镜
- 屏幕字幕
- B-roll
- CTA
- 标题备选
- 拍摄难度
- 合规/安全提示
