# drone-content-coach

> 低空行业 AI 短视频编导 Skill

把无人机培训、飞手作业、教练教学、企业产品、真实工作场景和从业者个人经验，转化为**能拍、能发、能建立IP、能服务真实业务目标**的短视频内容。

可直接将该skill安装至豆包、WorkBuddy、Codex等工作只能体进行调用。

## 适用人群

- 无人机培训机构老板
- 无人机培训教练 / 讲师
- 吊运飞手
- 飞防飞手
- 其他无人机作业飞手
- 无人机厂家 / 产品经理 / 工程师 / 老板
- 低空行业团队账号
- 不愿真人出镜、采用实拍+AI配音或AI数字人的账号

## 核心能力

### 1. 账号初始化与诊断

建立账号、行业角色、企业/个人/团队身份、目标受众、商业目标、内容边界等基础档案，并据此分析账号目前的问题。

### 2. 出镜人与人物库

不仅判断“是否真人出镜”，还识别：

- 固定真人
- 多人轮换
- 真人偶尔出镜
- 无真人
- AI配音
- AI数字人

对于真人出镜者，通过轻量性格测试建立人物卡，包括性格、表达方式、专业身份、镜头状态和语言指纹。

### 3. 低空行业选题

围绕真实行业问题、用户决策、搜索需求、行业热点、评论问题和真实场景生成选题。核心原则是“热点服务于内容，而不是内容服务于热点”。

### 4. 可执行脚本

输出口播、分镜、动作、机位、字幕、标题、CTA、拍摄难度和安全/合规提醒。

### 5. 现场导演

用户可以上传训练场、农田、吊运施工现场、工厂、仓库等真实照片或视频。Skill 会把已有脚本重新改造成更适合真实场地的版本。

### 6. 直播辅助

提供开场、互动、答疑、转化和风险表达检查。涉及动态平台规则时，应以最新官方规则为准。

### 7. 数据复盘

从播放、留存、互动、主页访问、私信、咨询、报名、找活等完整链路分析，而不是只追求播放量。

## 使用方式

不同 Agent 客户端的安装方式不同。完成安装后，如果客户端支持 slash commands，可以使用类似：

```text
/drone-content-coach init
```

首次使用建议先完成初始化。

后续可使用：

```text
/drone-content-coach diagnose
/drone-content-coach persona
/drone-content-coach topic
/drone-content-coach script
/drone-content-coach scene
/drone-content-coach plan
/drone-content-coach live
/drone-content-coach review
/drone-content-coach rules
```

如果客户端不支持 slash commands，可直接用自然语言表达相同需求。

## 设计理念

**不是“替你写一条爆款文案”，而是让 AI 像一个长期跟着低空行业从业者工作的短视频编导。**

每次内容工作都要回答：

> 谁来拍？
>
> 为什么拍？
>
> 给谁看？
>
> 拍什么？
>
> 在哪里拍？
>
> 怎么拍？
>
> 怎么说？
>
> 最终希望用户做什么？
