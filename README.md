# drone-content-coach

> 无人机行业 AI 内容教练 Skill

把无人机培训、飞手作业、教练教学、企业产品、真实工作场景和从业者个人经验，转化为**能拍、能发、能建立IP、能服务真实业务目标**的短视频内容。

可直接将该skill安装至豆包、WorkBuddy、Codex等工作智能体进行调用。当前版本还不是特别智能，所以输出的内容仅供参考，不能直接使用。

## 适用人群

- 无人机培训机构老板
- 无人机培训教练 / 讲师
- 吊运飞手
- 飞防飞手
- 其他无人机作业飞手
- 无人机厂家 / 产品经理 / 工程师 / 老板
- 低空行业团队账号
- 不愿真人出镜、采用实拍+AI配音或AI数字人的账号

## 核心能力

### 1. 账号初始化与诊断

建立账号、行业角色、企业/个人/团队身份、目标受众、商业目标、内容边界等基础档案，并据此分析账号目前的问题。

### 2. 出镜人与人物库

不仅判断“是否真人出镜”，还识别：

- 固定真人
- 多人轮换
- 真人偶尔出镜
- 无真人
- AI配音
- AI数字人

对于真人出镜者，通过轻量性格测试建立人物卡，包括性格、表达方式、专业身份、镜头状态和语言指纹。

### 3. 低空行业选题

围绕真实行业问题、用户决策、搜索需求、行业热点、评论问题和真实场景生成选题。核心原则是“热点服务于内容，而不是内容服务于热点”。

### 4. 可执行脚本

输出口播、分镜、动作、机位、字幕、标题、CTA、拍摄难度和安全/合规提醒。

### 5. 现场导演

用户可以上传训练场、农田、吊运施工现场、工厂、仓库等真实照片或视频。Skill 会把已有脚本重新改造成更适合真实场地的版本。

### 6. 直播辅助

提供开场、互动、答疑、转化和风险表达检查。涉及动态平台规则时，应以最新官方规则为准。

### 7. 数据复盘

从播放、留存、互动、主页访问、私信、咨询、报名、找活等完整链路分析，而不是只追求播放量。

## 使用方式

在自己日常使用的 Agent 平台（如Codex/ChatGPT桌面版、WorkBuddy、豆包、Claude、Kimi等），输入以下文本：

```text
https://github.com/ganjiaolian-UAVcoach/drone-content-coach 请帮我将这个 skill 安装到我的技能中，以便于我后期的调用
```
如果 Agent 不太智能，或者说输出的结果不如你意。

可使用以下文本：

```text
安装 github 上的 ganjiaolian-UAVcoach/dorne-cotent-coach 的 skill项目
```

如果 Agent 客户端还是未能如你意，或长时间卡住；请尝试停止进程并关闭客户端，再关闭加速器等平台，重新打开 Agent 客户端，再次进行安装。

## 设计理念

**不是“替你写一条爆款文案”，而是让 AI 像一个长期跟着低空行业从业者工作的短视频编导。**

每次内容工作都要回答：

> 谁来拍？
>
> 为什么拍？
>
> 给谁看？
>
> 拍什么？
>
> 在哪里拍？
>
> 怎么拍？
>
> 怎么说？
>
> 最终希望用户做什么？
